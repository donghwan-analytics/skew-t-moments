*Explicit formulae for moments of the multivariate skew-t distribution*
## 연구 개요
비대칭성과 두꺼운 꼬리를 함께 표현하는 skew-t 분포는 평균과 분산을 넘어 고차·혼합 적률이 필요할 때 계산이 복잡해집니다. Azzalini–Capitanio 다변량 skew-t에서 **각 변수의 차수를 지정한 일반적인 원적률(raw moment)**을 체계적으로 계산하는 식을 연구했습니다.
## 담당 업무 및 주요 기여
제1저자로서 혼합 표현과 가법 표현을 결합한 적률 유도, 표준형에서 일반 위치·척도 형태로의 확장, 대칭분포로의 환원과 수치 검증을 다루었습니다. 연구 과정과 검증 기준을 원고·학습노트·R 코드로 정리했습니다.
## 연구 방법
| 단계 | 판단과 접근 |
| --- | --- |
| 1. 존재 조건 확인 | 전체 차수 &#124;k&#124;가 자유도 ν보다 작은 범위에서 적률을 다룸 |
| 2. 꼬리의 영향 분리 | Scale-mixture 표현으로 혼합변수의 역적률을 Gamma 함수 항으로 분리 |
| 3. 비대칭 구조 분해 | Skew-normal의 가법 표현을 통해 half-normal과 Gaussian 성분으로 구성 |
| 4. 혼합 적률 계산 | 다중지수 전개와 Isserlis형 Gaussian 적률로 표준형 일반식을 정리 |
| 5. 일반형으로 확장 | 위치·척도 변환을 반영해 일반 모수의 원적률로 확장 |
**주요 기술 과제:** 변수가 여러 개이면 차수 조합과 교차항이 증가합니다. 각 경우를 따로 계산하는 대신, 다중지수로 전체 구조를 표현하고 각 성분의 적률을 조합하는 방식으로 정리했습니다.
## 검증 방법
### 수학적 환원
비대칭 모수가 0일 때 다변량 Student t의 적률로 환원되는지 확인했습니다. 일반식의 특수한 경우가 알려진 결과와 일치하는지를 검토하는 기준입니다.
### 독립적인 계산 경로
이변량 검증 코드에는 유도식과 `sn::dmst` 밀도에 대한 수치적분을 비교하는 절차가 있습니다. 표준형과 일반형을 별도 파일로 나누고, 선택적으로 `sn::rmst` 모의표본을 이용한 비교도 구성했습니다.
### 성립 범위 명시
적률의 전체 차수가 자유도 이상이면 공식의 적용 범위를 벗어나는지 확인합니다. 수치적분의 오차와 고차 계산의 조합적 복잡도 역시 검증 결과를 해석할 때 고려해야 합니다.
## 주요 결과 및 의의
특정 저차 적률에 머무르지 않고, 성립 조건 안에서 임의의 다중지수에 대응하는 원적률의 명시적 표현을 정리했습니다. 표준형·일반형·대칭형을 연결해 계산 구조를 일관되게 설명했습니다.
